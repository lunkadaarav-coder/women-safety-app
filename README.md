# women-safety-app

Women Safety & Risk Zone Mapping App - a full-stack web application with real-time safety reporting, SOS emergency system, interactive heatmap, trusted contacts, and community validation.

## Person 3: SOS + Live Tracking

This branch contains the emergency response module:

- One-tap SOS button
- Browser geolocation based live location sharing
- Simulated real-time tracking updates
- Optional voice-triggered SOS using the Web Speech API
- Fake call escape screen

## Run locally

```bash
npm install
npm run dev
```

On Windows PowerShell, use `npm.cmd` if script execution is blocked:

```bash
npm.cmd install
npm.cmd run dev
```
